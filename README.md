# Sri Krushi Bhandara - AI-Powered Agricultural Solutions Platform

**Smart Agricultural Solutions for Better Crops**

Sri Krushi Bhandara is a modern, production-ready agricultural platform serving farmers in Halebeedu, Karnataka with fertilizers, crop protection products, micronutrients, biostimulants, and AI-powered crop guidance.

## 🌾 Features

### Core Features
- 🛒 **Product Catalog** - Searchable, filterable agricultural products
- 🤖 **AI Crop Doctor** - Upload crop images for AI-assisted analysis
- 💬 **24/7 AI Chatbot** - Agricultural advisory powered by Llama
- 🌾 **Crop Knowledge Library** - Comprehensive crop guides
- 🔍 **Crop Problem Identifier** - Visual disease/pest detection guide
- 📚 **Nutrient Deficiency Guide** - Interactive nutrient management
- 📱 **Bilingual Support** - Kannada + English interface
- 🏪 **Store Locator** - Maps and contact integration
- 👨‍💼 **Admin Dashboard** - Product and knowledge management
- 📊 **Analytics** - Track AI usage and farmer engagement

## 🏗️ Tech Stack

### Frontend
- React 18 + Vite + TypeScript
- React Router, TanStack Query, Tailwind CSS

### Backend
- FastAPI + Python 3.11+
- SQLAlchemy ORM, PostgreSQL

### AI & Knowledge
- Llama for crop analysis and advisory
- PostgreSQL pgvector for semantic search
